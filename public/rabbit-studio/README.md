# 兔耳角色素材

打开 `index.html` 可预览四款头像及三款循环 GIF，也可在博客预览服务中访问 `/rabbit-studio/`。

## 博客头像

每款有 1024 × 1024 PNG 和可缩放 SVG；圆形头像的四角透明。

| 文件名 | 内容 | 配色 |
| --- | --- | --- |
| `avatars/rabbit-01-welcome` | 挥手欢迎 | 奶油金 |
| `avatars/rabbit-02-reading` | 读书写作 | 薄荷绿 |
| `avatars/rabbit-03-coding` | 戴眼镜、敲代码 | 薰衣草紫 |
| `avatars/rabbit-04-coffee` | 咖啡时间 | 晴空蓝 |

## 动态表情

每款提供 512 × 512 GIF：32 帧、每帧 80 ms、2.56 秒无限循环。主文件 `.gif` 为透明背景，`-cream-bg.gif` 为奶油色背景。另有 640 × 640 透明 PNG 和 SVG 动作截图。

| 文件名 | 表情 | 动作与配字 |
| --- | --- | --- |
| `emotes/rabbit-01-worship` | 膜拜 | 双手合十、点头行礼；大佬，受我一拜！ |
| `emotes/rabbit-02-helpless` | 无奈 | 摊手、摇头、叹气；我能怎么办呢… |
| `emotes/rabbit-03-angry` | 愤怒 | 握拳、抖动、冒气；气鼓鼓！ |

透明 GIF 使用 GIF 格式的二值透明；需要更平滑的静态边缘时使用 PNG 或 SVG。

`avatars-preview.png` 为四款头像对比，`emotes-preview.gif` 为三款动画并排预览，`rabbit-studio-preview.png` 为全套静态总览。

网站图标与六款配色仍在 `../favicon/`，本套素材没有替换网站当前头像或图标。
